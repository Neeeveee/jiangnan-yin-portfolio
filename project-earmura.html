Project Overview

EARMURA is an interactive narrative project delivered as a live website and a narrative video. The website lets users enter the story through voice-based interaction, while the film extends the same world into a cinematic experience.

Project Type

Personal Project / Interactive Narrative / Web Prototype / System Design

My Contribution

Website prototype, interaction flow, narrative structure, visual direction, Web Audio interaction and front-end implementation

Duration

1 month / 2025

Deliverables

Live interactive website, narrative film, interface visuals and interaction flow

Tools

HTML, CSS, JavaScript, Web Audio API, narrative systems and audiovisual direction

Validation Status

Working prototype and narrative film completed; formal user testing was not part of this one-month prototype sprint.

Website Prototype

The live website is the main final outcome.

The portal turns the project from a static concept into an interactive experience. Users move through the narrative through web pages, voice input, waveform feedback and response states.

Narrative Video

The film shows the world and emotional logic behind the interface.

The narrative video works as the second final output. It gives context to the website experience, showing the atmosphere, roles and consequences that the interface only hints at.

My Contribution

I connected the story, interface and prototype into one deliverable.

My role covered the full experience: shaping the narrative premise, designing the web interaction, building the front-end prototype and directing the visual rhythm of the website and film.
